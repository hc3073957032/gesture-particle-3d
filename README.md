# Gesture Particle Universe · 手势粒子宇宙

基于 Three.js + MediaPipe 的实时交互式 3D 粒子系统，单个 HTML 文件即可运行，无需构建、无需依赖安装。

## 功能

- **手势控制**（摄像头）
  - 手掌张合 → 粒子群缩放与扩散
  - 手指摇摆 → 旋转 / 俯仰
  - 单指远近 → 粒子距离
- **7 个内置模型**：爱心、花朵、土星、烟花、地球、千里江山、昙花
- **自定义图片**：上传 / 拖拽 / 粘贴本地图片，自动解析为粒子点云（支持立体浮雕、灰度上色、深度调节）
- **颜色调节**：主色调 + 色板、混色强度、色相偏移、饱和度、明度
- **渲染**：自定义 GLSL 点精灵 + UnrealBloom 辉光 + 星空背景
- 全屏按钮、FPS / 手势状态 HUD、鼠标 / 触控回退控制

## 运行

下载 `particle-gesture-3d.html` 后直接在浏览器打开即可。

摄像头需在安全上下文授权，推荐使用 Chrome / Edge；如需手势控制，建议用本地服务打开：

```bash
python -m http.server 8000
# 浏览器访问 http://localhost:8000/particle-gesture-3d.html
```

## 快捷键

| 按键 | 功能 | 按键 | 功能 |
|---|---|---|---|
| 1~7 | 切换模型 | F | 全屏 |
| C | 摄像头手势 | H | 收起 / 展开面板 |
| R | 重置视角 | 空格 | 自动旋转 |

## 说明

- 首次加载需要联网（Three.js 与 MediaPipe 走 jsDelivr CDN）。
- 图片仅在本地 Canvas 中处理，不会上传到任何服务器。
